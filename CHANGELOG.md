# Changelog

All notable changes to **Ambient Home** are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.2] - 2026-11-27

Performance, APK compression, and security-polish release (`versionCode=20`) eliminating every remaining per-frame `onDraw()` allocation, shrinking APK size by `23.75%` (`-974.8 KB`) via exact `1920×1080` WebP wallpapers, isolating network I/O from local UI I/O, cutting idle/resume IPC and Sleep Timer wakeups, and closing all remaining LOW audit items.

### Performance & Compression
- **True Zero-Allocation `onDraw()` Hot Path (`ui/HomeSurfaceCache.kt`, `model/AmbientModels.kt`, `ui/HomeWidgetsRenderer.kt`, `ui/TopBarRenderer.kt`):** Replaced per-frame concatenated cache keys in `ensureWeatherPill` and `ensureSleepPill` with zero-alloc primitive/reference fields; converted `NowPlayingState.displayTitle`/`displaySubtitle`, `WeatherSnapshot.pillTempText`/`ambientSummary`, and `SleepTimerState.badgeText` into stored `val`s computed once at construction; removed the redundant `syncVisibleActions()` call inside `TopBarRenderer.draw()`; evicted `dockBgBmp` when switching to `GRID` (mirroring `gridBgBmp` eviction in `DOCK`, still `0` HWUI `.recycle()`).
- **16:9 `1920×1080` WebP Built-In Wallpapers (`res/drawable-nodpi/w1..w5.webp`):** Center-cropped all 5 bundled wallpapers to exact `1920×1080` and re-encoded as high-quality lossy WebP (`q=85`, `method=6`, 0 EXIF), cutting bundled wallpaper size from `3,713,277 B` to `2,732,706 B` (`-980,571 B` / `-26.4%`), shrinking the signed APK from `4,105,175 B` (`3.91 MiB`) to `3,130,332 B` (`2.99 MiB`), and cutting `w1` decode peak RAM by 25%.
- **Split `localIo` vs `netIo` + Weather Offline Backoff (`MainActivity.kt`, `data/WallpaperController.kt`, `MainFeatureCoordinator.kt`, `data/WeatherClient.kt`):** Separated fast local I/O (`PackageManager`, wallpaper baking, Wi-Fi status) from external HTTPS (`Open-Meteo`, `Bing`/`Wikimedia`) so offline outages can never head-of-line block local UI; added synchronized `fetchLock` in-flight deduplication and 15-minute monotonic failure backoff to `WeatherClient`.
- **Smart Sleep Timer Wakeups & Redraws (`data/SleepTimerController.kt`, `ui/HomeCanvasView.kt`):** Stopped `tickTask` completely while detached in background (`0` background ticks; `AlarmManager` handles firing) and resumed cleanly on `attachListeners()`; aligned foreground ticks to exact minute boundaries when `remainingSec > 60` and 1s ticks only in the final 60s window; guarded `HomeCanvasView.setWidgetsState()` so unchanged `active`/`badgeText`/`warningActive` skips `syncTopMeta()` + `invalidate()`.
- **1-IPC `PackageManager.getChangedPackages()` Fast Path & `prepareToDraw()` (`MainActivity.kt`, `data/AppRepository.kt`):** Tracked `lastPkgSeq` across `onResume()` so routine HOME returns probe package changes in 1 Binder IPC instead of a 25–30 IPC full rescan (still refreshing on first load, package broadcasts, Settings return, launch failures, or WoL/layout edits); added `masked.prepareToDraw()` on baked tile bitmaps.
- **Micro-Optimizations (`data/LanWebRemoteServer.kt`, `data/WallpaperRepository.kt`, `data/MediaSessionBridge.kt`, `data/SystemStatusHelper.kt`):** Guarded `applyRemainingTimeout()` with `if (input.available() == 0)` to eliminate hundreds of per-byte `setsockopt` syscalls per request; enabled core thread timeout (`30s`) on the HTTP worker pool; switched `customFilesSignature()` to metadata-only `stat()` checks (verifying magic headers on playlist load/decode); cached `lastPkg -> lastLabel` in `MediaSessionBridge.resolveAppLabel()`; added early-break in `SystemStatusHelper.readMemInfoKbFrom()` once both `MemTotal` and `MemAvailable` are read.

### Security, Accessibility & Script Lint
- **Bounded HTTP Worker Queue (`503`) & Monotonic PIN Lockout (`data/LanWebRemoteServer.kt`, `data/LanWebRemoteRouter.kt`):** Replaced unbounded `newFixedThreadPool(4)` with a bounded `ThreadPoolExecutor(4, 4, 30s, ArrayBlockingQueue(32))` returning clean `503 Service Unavailable` (`service_unavailable`) on saturation; switched the 15s PIN lockout to monotonic `SystemClock.elapsedRealtime()` (with JVM fallback).
- **HTTPS Image Host Allowlist (`data/OnlineWallpaperProvider.kt`):** Enforced strict `https://` host allowlist (`bing.com`, `*.bing.com`, `upload.wikimedia.org`, no userinfo, standard port 443) in `parseBingJson()`, `parseWikimediaJson()`, and pre-/post-redirect in `downloadJpeg()`.
- **PWA Error Parity & WCAG 1.4.11 Contrast (`res/raw/web_remote.html`):** Added Russian mappings for `forbidden_package`, `bridge_not_running`, and `service_unavailable` in `ERR_MAP`; raised `--bd` border contrast to `rgba(255,255,255,.34)` (`3.04:1–3.11:1 >= 3.0:1` WCAG 1.4.11 across all dark surfaces).
- **Shell & PowerShell Lint Polish (`build.sh`, `scripts/install-tv.sh`, `fetch-toolchain.ps1`):** Silenced `shellcheck SC1007` (`CDPATH='' cd`) and `PSScriptAnalyzer PSShouldProcess` (`[CmdletBinding(SupportsShouldProcess = $true)]` on `Install-Archive`).
- **Verification:** `645/645` pure-JVM unit tests PASS (`+54` new regression tests) + `60/60` Node VM PWA & WCAG checks PASS (`0` unhandled rejections).

## [3.0.1] - 2026-11-27

Hardening & polish release (`versionCode=19`) fixing all concurrency, blackout, security, and accessibility issues identified during full static and PWA audits.

### Fixed
- **Sleep Timer Idempotency, AudioFocus & Mid-Fade Cancel (`data/SleepTimerController.kt`):** Added a thread-safe generation/armed state machine (`SleepTriggerState`), always cancels pending `AlarmManager` alarms on fire so late inexact alarms can never double-execute the sleep sequence, tracks & abandons `AudioFocusRequest` cleanly after pause, cancels pending fade/restore `Runnable`s on `cancel()`, immediately restores original `STREAM_MUSIC` volume if cancelled mid-fade, and holds `goAsync()` safely through the fade window with 0 extra permissions.
- **Sleep Blackout 3 Edge Cases (`MainActivity.kt`, `ui/HomeCanvasView.kt`, `ui/WallpaperSurfaceView.kt`):** Cancels `ambientIdleTask` on `enterSleepBlackout()` and `onResume(blackoutOnResume=true)` so idle timeout never wakes blackout back to bright wallpaper; decouples blackout rendering from `showClock` (`AmbientOverlayData.showClock`) so `WallpaperSurfaceView` draws solid `Color.BLACK` even with clock disabled; forces immediate `syncAmbientClock()` (`0ms` blackout latency) even when already in Ambient Mode.
- **Multi-Thread `LauncherStore` Atomicity (`data/LauncherStore.kt`, `LanWebRemoteService.kt`):** Synchronized all `LauncherStore` read-modify-write mutations and initial PIN generation on a process-wide companion `STORE_LOCK` so concurrent writes from `MainActivity`, `SettingsActivity`, and Web Remote worker threads never clobber each other.
- **Chained Dialog Async `OnDismissListener` Race (`MainActivity.kt`, `SettingsActivity.kt`, `MainFeatureCoordinator.kt`, `SettingsExtraHelper.kt`):** Identity-checked every dialog dismiss (`if (activeDialog === dlg)`) via `onDialogShown`/`onDialogDismissed` so dismissing dialog #1 never clears `activeDialog` for newly opened dialog #2; cancelled `bootTickTask` in `onPause()` and guarded async UI callbacks with `isFinishing || isDestroyed`.
- **Analog Clock 4-Corner Safe-Zone (`model/AmbientModels.kt`, `ui/AmbientClockRenderer.kt`):** Computed safe vertical and horizontal geometry (`AmbientClockLayout`) across 720p/1080p/4K so `ANALOG` (and `CINEMA`/`THIN`/`MINIMAL`) meta and Now Playing lines never clip vertically (`<= 1044u`) or horizontally on left/right screen edges, with surrogate-safe ellipsizing.
- **Online Wallpapers & Weather Resilience (`data/OnlineWallpaperProvider.kt`, `data/WeatherClient.kt`):** Accumulated JPEG header bytes across partial TLS reads in `streamWithMagicCheck`; sorted daily wallpaper cache eviction by `lastModified()` descending (preventing `daily_wiki_*.jpg` from pinning over newer Bing images); synchronized `refreshIfDue` with 15-minute offline failure backoff; capped all HTTP JSON reads at 256 KiB (`262_144` bytes); switched `WeatherClient` to a single `@Volatile` immutable cache entry with monotonic elapsed-realtime staleness.
- **Media & Audio Observer Lifecycle (`data/MediaSessionBridge.kt`, `data/AudioDeviceObserver.kt`):** Guarded queued main-handler callbacks after `stop()` so paused transitions can never leak a `MediaController.Callback` or stale `AudioDeviceCallback`.
- **LAN Web Remote Performance & Concurrency (`data/AppRepository.kt`, `LanWebRemoteService.kt`, `data/WallpaperRepository.kt`):** Added 30s lightweight app-list cache (`loadLightweight`, 0 bitmap baking) for `/api/status`; added `@Volatile` on `cachedHtml`, `AtomicBoolean` in `commitClipboardSync`, `finally` `.tmp_*` cleanup in `saveViaDirectFile`, and aligned `WallpaperRepository` custom image discovery to `64..35_000_000` bytes with magic-header verification (JPEG/PNG/WebP).
- **MiniJson & HomeWidgetsRenderer Polish (`model/MiniJson.kt`, `ui/HomeWidgetsRenderer.kt`):** Required 4 strict hex digits `[0-9a-fA-F]` in `\uXXXX`, bounds-checked `asInt`, rejected `Infinity`/`NaN`, and pre-built `"♫  $subtitle"` off-frame with exact `maxW` truncation and surrogate-safe ellipsizing.

### Security & Accessibility
- **No Plaintext PIN in JSON Backups (`data/SettingsBackupCodec.kt`):** Omitted `webRemote.pin` on JSON export and preserved the existing device PIN on import so `/sdcard/Download/ambient_home_backup.json` never stores a plaintext PIN.
- **HTTP Slowloris Deadlines & Security Headers (`data/LanWebRemoteServer.kt`, `data/LanWebRemoteRouter.kt`):** Enforced total `10s` header / `30s` body deadlines (`408 Request Timeout`), added `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, and strict `Content-Security-Policy`, handled clean TCP EOF without returning `431`, eliminated duplicate auth checks, and added `Expect: 100-continue` support.
- **LAN Web Remote PWA Reliability & WCAG 2.2 AA (`res/raw/web_remote.html`):** Eliminated all unhandled promise rejections across all 12 action handlers and timers; prevented rejected `429`/offline PINs from being saved to `localStorage`; added centralized Russian error mapping (`errMsg`, never `"Ошибка: undefined"`); cleared `#pinInput` and `#loginErr` on logout and `401`; enabled pinch-to-zoom, `:focus-visible`, `prefers-reduced-motion`, `<main>` landmark, `aria-label` on all 11 icon buttons and 6 inputs/selects, `role="status"` / `role="alert"`, `>= 44x44px` touch targets, whitelisted AFR rates `[0,24,25,30,50,60]`, Enter-key submission, and upload busy/0-byte guards.
- **Verification:** `591/591` pure-JVM unit tests PASS (`+100` new regression tests) + `60/60` Node VM PWA behavioral & WCAG tests PASS (`0` unhandled rejections).

## [3.0.0] - 2026-11-27

First public open-source release (`versionCode=18`).

### Added
- **Auto-Night Cinema Mode (`model/NightSchedule.kt`):** Configurable schedule (default `22:00-07:00`) plus Auto/On/Off toggle; bakes warm amber cinema tint and deeper dimming directly into static `RGB_565` wallpapers off the UI thread (`0%` extra GPU load) and lowers clock luminance.
- **Quick Control Sheet (`TvDialogs.showQuickControls`):** One-click living-room drawer via the TopBar Quick button or `MENU` key — Ambient Now, Next Wallpaper, Night Cinema toggle, Sleep Timer, LAN Web Remote info (URL + PIN), Soft Wi-Fi Reconnect, and Safe USB Eject (when external USB storage is mounted).
- **4 Ambient Clock Styles & Burn-in Protection (`ui/AmbientClockRenderer.kt`):** Thin, Cinema, Minimal, and Analog clocks with 15-minute 4-corner burn-in hop and subtle pixel drift.
- **Living-Room Sleep Timer (`data/SleepTimerController.kt`, `SleepTimerReceiver`):** 15/30/60/90-minute timer with TopBar & Ambient countdown badge, 15-second cancelable pre-sleep warning, smooth volume fade-out + media pause, and transition to ultra-dim black Night Ambient (plus optional HDMI sleep when a root bridge FIFO is present).
- **Zero-Scan Bluetooth Audio Indicator (`data/AudioDeviceObserver.kt`):** Passive `AudioManager.AudioDeviceCallback` showing a TopBar headphones badge only while BT A2DP / BLE headset audio is connected, with 0 Bluetooth scans.
- **Open-Meteo Weather Widget (`data/WeatherClient.kt`):** Optional, API-key-free weather pill and 4-day / hourly forecast dialog with RAM-only caching (refreshes at most every 45 minutes while `HOME` is active).
- **Now Playing Pill (`data/AmbientNotificationListener`, `data/MediaSessionBridge.kt`):** Optional zero-idle-cost media bar showing active playback metadata on Home and Ambient screens once `NotificationListener` access is granted.
- **Photo of the Day Wallpapers (`data/OnlineWallpaperProvider.kt`):** Optional Bing HPImageArchive + Wikimedia Commons POTD daily wallpaper fetcher (at most once every 12 hours, max 3 cached validated JPEGs, automatic offline fallback).
- **LAN Web Remote PWA & REST API (`LanWebRemoteService`, `LanWebRemoteRouter`, `res/raw/web_remote.html`):** Embedded mobile/desktop web remote on port `:8765` with 6-digit `SecureRandom` PIN (`X-Auth-Token`, constant-time verification, 5-failure 15s `429` lockout), live device telemetry, app launcher, Night Mode / Sleep Timer / Weather / WoL controls, wallpaper upload (10 MiB cap + magic byte validation), and optional root-bridge D-pad / clipboard paste / AFR / force-stop / HDMI sleep support.
- **Wake-on-LAN PC Tile (`data/WolSender.kt`, `model/CustomShortcuts.kt`):** Optional virtual app tile to wake a configured LAN PC via UDP magic packet.
- **Wi-Fi-Aware Cold-Boot Auto-Launch (`model/BootAutoLaunch.kt`):** Optional cold-boot app launcher using `/proc/sys/kernel/random/boot_id` with network-wait and cancelable countdown banner.
- **JSON Settings Backup & Restore (`data/SettingsBackupCodec.kt`):** Human-readable JSON export/import of dock order, pinned/hidden apps, appearance, night schedule, weather city, WoL target, and Web Remote settings.
- **Cross-Platform Standalone Build & CI:** Portable Windows (`fetch-toolchain.ps1` + `build.ps1`) and POSIX Linux/macOS (`build.sh`) build scripts with environment-variable release signing (`AMBIENT_KEYSTORE*`), SHA-256 checksum output, and GitHub Actions CI.

### Changed
- **Deslop Modular Architecture:** Split `MainActivity`, `HomeRenderer`, and `WallpaperSurfaceView` into clean deep modules (`WallpaperController`, `TopBarRenderer`, `AmbientClockRenderer`, `MainFeatureCoordinator`, `MainSystemObservers`, `SettingsExtraHelper`) with strict `< 600` line file limits and zero circular dependencies.
- **Cross-Device Hardware Telemetry:** Generalized `SystemStatusHelper` GPU devfreq and thermal discovery to support Rockchip, Amlogic, Qualcomm, MediaTek, and generic Android TV devices with graceful fallbacks.
- **Unrooted Stock Android TV Polish:** Web Remote PWA and Sleep Timer / NotificationListener dialogs cleanly adapt when the optional root bridge FIFO is absent.

### Security & Hygiene
- Stripped EXIF metadata from bundled drawable wallpapers (`w4.jpg`, `w5.jpg`) while preserving National Park Service Public Domain attribution.
- Moved default debug keystore path to `build/debug.keystore` and enforced release signing via environment variables only.
- Verified `491` pure-JVM unit tests, R8 shrinking, `apksigner` v2+v3 signatures, `zipalign -p 4`, and uncompressed 4-byte-aligned `STORED` `classes.dex`.
